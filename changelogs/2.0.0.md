# Version 2.0.0

## Features

- Fullscreen gallery mode for media previews
- Navigation arrows and index display in preview modal
- List view thumbnails for images and videos
- Configurable larger preview modal for images/videos
- Arrow key navigation in preview modal
- Batch selection and deletion
- Directory search results
- Context menu for files and folders
- Video thumbnail generation
- Streaming zip download for directories
- URL history navigation and infinite scroll

## Improvements

- Mobile responsive header and breadcrumbs
- CSS and JS refactored for modularity and DRY
- Wake Lock during upload operations
- Lazy caching with filesystem as source of truth

## Bug Fixes

- Preview modal content flash during navigation
- Breadcrumb left-ellipsis truncation
- File highlight persistence on preview close
- Delete resets scroll position
- Mobile action buttons overflow
