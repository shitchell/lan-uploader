#  Core Documentation

### About These Documents

This directory contains the foundational documents that define a project's timeless vision. They are the ultimate source of truth for *what* we are building, *how* we build it, and *why*.

### Document Guide

*   **`identity.md`**: The **"What & Who."** Read this to understand the project's core mission, its target audience, and its non-negotiable boundaries.
*   **`principles.md`**: The **"How."** Read this to understand the rules for making technical and design decisions, from high-level architecture to testing philosophy.
*   **`values.md`**: The **"Why."** Read this to understand the project's culture, ethics, and the development craft we aspire to.

### How to Use These Docs

When faced with a fork in the road, consult these documents in order:
1.  Does your choice align with our **Identity**?
2.  Does it follow our **Principles**?
3.  Does it reflect our **Values**?
